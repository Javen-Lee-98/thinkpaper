# inkpad：手写草稿纸接入 Claude Code

让平板上的手写草稿纸成为 Claude Code 对话的另一种输入方式。你在平板上写写画画，点「AI」，这一页就会作为一条消息进入电脑上正在进行的对话。Claude 读的是你的手写图像和书写过程（先写什么、在哪停顿、擦掉了什么），同时带着这个对话的上下文和项目文件；回应写回草稿纸（批改符号、圈画、短批注、示意图、公式；长回答收在圈号里，点开是一张卡片），对话里只留一句话。

草稿纸页面和中转服务在本仓库的 `inkthink` 文件夹，安装和用法见仓库根目录的 README。

插件提供：
- 把平板投递送进对话（每 1.5 秒向本机中转服务取一次）
- 工具 `ink_reply`（批注写回草稿纸）、`ink_show`（把图片、PDF / Word / PPT 的某一页或文本文件推到平板上供圈画）、`ink_snapshot`（取平板当前页）、`ink_import`（把整份文档导入成本子，同一个文件再导入就原地更新）、`ink_scan`（整本检测：写过字的每一页）、`ink_confirm`（在平板上问拿不准的字迹）、`ink_ask`（在平板顶上发问话卡片：要你回答才能继续的问题，或纸上放不下的结果）、`ink_edit`（改导入的文档之前，在平板上问覆盖原文件还是另存一份，并先留底）
- 取到投递、交进对话之后才告诉服务「收到了」，服务才删；交不进去时服务过一会儿再给，同一条不会交两遍
- 命令 `/ink`：启动服务（如未运行）、打开面板显示二维码；`/ink here`：平板上开着的那本改发到当前对话（每本记住自己的对话）；`/ink stop`：停止服务（之后不自动重新拉起，直到下次 `/ink`）
- 读取投递图片时不再弹权限确认
- 把这一轮的进展（排队、Claude 在看、在改文件、结束）报给服务，平板的「AI」按钮上显示
- 每一轮结束时，把这一轮在项目文件夹里新生成的图片、PDF、PPT、Word、Markdown 报给服务，平板上出一条提示，由你决定要不要加进草稿纸（插件设置 `offer_new_files` 可以关掉）
- 确认字迹最多等约 45 秒；问话卡片的问题最多等约一分半，没答就停手等着，之后的回答作为新消息送来
- 写回批注时服务查出来的话（短批注写长了收成圈号、缺理由的批改符号退回、还缺哪几组的读法）一条一行接在 `ink_reply` 的结果后面

服务开着时，草稿纸的固定规则由服务给（`prompt.py` 的 `protocol()`），插件放进系统提示，每个对话一次；投递里只放这一页的内容。服务没开时插件什么也不做，也不往系统提示词里加内容。
